# LifeSpan docs

Public pages for Google Play and related listings.

## Privacy Policy

- Markdown: [privacy-policy.md](./privacy-policy.md)
- HTML (recommended for Play Console): [privacy-policy.html](./privacy-policy.html)

### Publish with GitHub Pages

1. Push these files to GitHub (`markadmin28/LifeSpan`).
2. Repo **Settings → Pages**.
3. Source: **Deploy from a branch**.
4. Branch: `main` (or your default), folder: **/docs**.
5. Save, wait 1–2 minutes.
6. Open:

`https://markadmin28.github.io/LifeSpan/privacy-policy.html`

7. Paste that URL into Play Console → App content → Privacy policy.
